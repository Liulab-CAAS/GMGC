# Grassland Dark Proteome — Analysis Commands

This repository shows the main analysis commands, parameters and file descriptions. **Some inputs (such as filtered similarity graphs, seed MSAs and structural clusters) must be generated by the original post-processing workflow. These command examples are not a complete end-to-end reproducibility pipeline.**

| File | Purpose |
|---|---|
| `01_Tantan_LAST_HipMCL.sh` | Low-complexity masking, sequence comparison and protein-family clustering. |
| `02_Clustal_Pfam.sh` | Family sequence alignments and Pfam-A re-screening. |
| `03_ESMFold.sh` | Run ESMFold v1 batch structure prediction. |
| `run_esmfold_batch.py` | Batch ESMFold inference used by Step 03. |
| `04_TM_align.sh` | Pairwise structural comparison and connected components. |
| `05_SCOPe_PDB_AFDB.sh` | SCOPe screening with TM-align, followed by PDB/AFDB searches with Foldseek. |
| `06_DeepFRI2.sh` | Predict protein functions using DeepFRI2. |

See each script header for input and output file descriptions. ESMFold quality filtering, structural representative selection and manual GO classification **are not fully automated by these simplified commands**.
